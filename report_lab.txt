Defensive lesson: secrets must never sit in process memory in plaintext. A password or key left in a plain variable can be read by anyone who can read the process memory — this scan just proved it. Programs that handle secrets lock the memory (mlock), zero the buffer as soon as they are done with it, and keep keys in a system keyring or a hardware-backed store instead of a variable.
